# Okeat - Project Overview

Interactive culinary map in Israel for filtering 20,000+ restaurants based on dietary preferences (Kosher, Vegan, Gluten-Free, Allergies).

## Tech Stack
- **Frontend:** Next.js (App Router), React, TypeScript, Tailwind CSS
- **Maps:** Mapbox GL JS / React Mapbox
- **Database & Backend:** Supabase (PostgreSQL + PostGIS for spatial queries)
- **Deployment:** Vercel

## Project Structure
- `/app` - Next.js App Router pages and API routes
- `/components` - UI elements and Mapbox map components
- `/lib/supabase` - Supabase client setup and spatial query helpers
- `/types` - TypeScript definitions and database models

## Commands
- `npm run dev` - Start development server
- `npm run build` - Build production bundle
